# xoleigh

Home page for xoleigh.com: small apps for friends and family (Wiki Walk, TV Rex).

Plain HTML/CSS/JS on GitHub Pages. No build step.

## Add an update

Open `updates.js`, copy a line, paste it at the top of the list, and change the date, app and text. The home page shows the newest 6.

## Turn on the Substack sign-up

In `site.js`, set `substackUrl` to your Substack address. The Subscribe button and sign-up box appear. Set `showWriting: true` once there's a post.

## Files

- `index.html` — the page
- `style.css` — the look (navy `#1F3A5F`, square corners, newspaper type)
- `updates.js` — release notes
- `site.js` — settings and the updates list
- `images/` — photos and app icons
- `CNAME` — the domain (xoleigh.com)
